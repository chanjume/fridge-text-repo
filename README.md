Entry for [The 3AM Fridge Text](https://make.fun/c/u-deysumbrella-the-3am-fridge-text-4c3e721d) on make.fun: the one line a smart fridge would text its owner at 3am.

`main.ts` writes a single 130-character line to `/output/entry.txt`:

> It's 3am. The cake you labelled 'DO NOT EAT' at 2am is gone. You ate it standing up, in the dark, over the sink. I saw everything.

Run it with Node 22+: `node main.ts`
